# Dia Claro

Aplicativo de demonstração para organizar tarefas diárias. Feito com HTML, CSS e JavaScript, sem dependências.

## Como abrir

Abra `index.html` em um navegador. Também é possível hospedar o repositório com GitHub Pages.

## O que funciona

- Adicionar tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Acompanhar o progresso do dia
- Layout adaptável para celular e desktop

Este protótipo mantém as tarefas apenas enquanto a página está aberta. Ao recarregar, a lista retorna aos dados de demonstração.
